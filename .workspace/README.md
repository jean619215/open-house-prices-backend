# 工作區說明

## 任務卡片命名
TASK-{三位數編號}-{標題}.md
例：TASK-001-backend-project-initialization.md

## 狀態流程
```
需求確認中
    ↓
QA撰寫測案
    ↓
開發中 ←────────────────────────┐
    ↓                           │
Code Review                     │（退回，≤ 3次）
    ↓ 通過                      │
QA測試 ─────────────────────────┘（QA 失敗退回開發中）
    ↓ 通過
完成
```

Code Review 退回超過 3 次 → 狀態改為「需求確認中」，與需求方重新討論。

## 歷程記錄格式
| 日期 | 角色 | 內容 |

內容一句話，說清楚「做了什麼」或「問題在哪」。
